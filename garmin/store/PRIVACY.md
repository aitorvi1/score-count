# Score Count — Privacy Policy

Last updated: 3 October 2026

Score Count is a standalone smartwatch scoreboard application.

## Data collected by the developer

**None.**

Score Count does not collect, transmit, sell or share personal data, usage data, location data or activity data with the developer or any third party.

## Data stored on the watch

The Garmin version stores only the information required for the scoreboard to work:

- the blue score;
- the red score;
- up to 25 previous score states used for local history/UNDO.

This information is stored locally using Garmin Connect IQ application storage.

It is not transmitted off the watch by Score Count.

## Permissions and external services

Score Count does not request access to:

- GPS or location;
- heart rate or health sensors;
- activity recording;
- contacts;
- network or Internet services;
- external accounts;
- advertising services;
- analytics services.

## Data deletion

Local Score Count data can be removed by uninstalling the application or clearing its application data through the Garmin device/platform controls available to the user.

## Children

Score Count does not knowingly collect personal information from children or adults because it does not collect personal information from users.

## Changes

If a future version introduces any feature that collects, transmits or shares user data, this policy will be updated before that version is published.
